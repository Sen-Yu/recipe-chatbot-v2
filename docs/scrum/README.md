# 스크럼

데일리 스크럼은 하루에 한 파일 `YYYY-MM-DD.md`(그날 아침 날짜), 주간 스크럼은 한 주에 한 파일 `YYYY-Www.md`(ISO 주차, 월~일)로 씁니다. 업무 번호는 [업무 플로우](../workflow.md)와 같습니다.

## 보드 3개와 마일스톤

| 보드 | 카드 | 칸 (Status) | 필드 |
|---|---|---|---|
| [① 업무](https://github.com/users/Sen-Yu/projects/1) | 업무 이슈 `[업무 번호] 업무 이름` | 결정 필요 · 할 일 · 진행 중 · 새벽 작업 · 검토 대기 · 완료 | 업무 번호, 담당, 주차(이번 주에 다루는 것만), 마일스톤 |
| [② 데일리 스크럼](https://github.com/users/Sen-Yu/projects/2) | `[데일리 스크럼] YYYY-MM-DD (요일)`, 라벨 `scrum:daily` | 작성 중 · 새벽 작업 검토 대기 · 검토 완료 | 날짜, 주차 |
| [③ 주간 스크럼](https://github.com/users/Sen-Yu/projects/3) | `[주간 스크럼] YYYY-Www (기간)`, 라벨 `scrum:weekly` | 이번 주 · 마감 | 주차 |

- **마일스톤**: [로드맵 단계](https://github.com/Sen-Yu/recipe-chatbot-v2/milestones)마다 하나씩 있습니다(0. 사전 결정 ~ 5. 2차 통합, L. 병행 업무). 업무 이슈는 자기 단계의 마일스톤에 들어가고, 마일스톤 화면에서 단계별 진행률을 봅니다.
- **데일리와 주간의 관계**: 데일리 스크럼 이슈는 그 주의 주간 스크럼 이슈의 하위 이슈입니다.
- **스크럼과 업무 카드**: 스크럼 본문에서 업무는 이슈 번호(`#40`)로 가리킵니다.

**올리는 방법**: 문서를 쓰거나 고친 뒤 `python3 scripts/scrum_sync.py <문서>`를 실행합니다. 이슈를 만들거나 본문을 고치고, 보드 필드도 채웁니다.

| 때 | 명령 |
|---|---|
| 아침 (데일리 새로 씀) | `scrum_sync.py docs/scrum/YYYY-MM-DD.md` → 작성 중 |
| 밤 (새벽 작업을 맡기고 잠) | `scrum_sync.py <데일리> --status review` → 새벽 작업 검토 대기 |
| 검토를 마침 | `scrum_sync.py <데일리> --close` → 검토 완료, 이슈 닫음 |
| 월요일 / 일요일 | `scrum_sync.py docs/scrum/YYYY-Www.md` / `--close` → 마감 |

## 네 가지 분류

| 분류 | 담는 것 | 누가 확인했나 |
|---|---|---|
| **어제 한 일 (Done)** | 어제 함께 진행해서 사용자가 확인한 일 | 확인함 |
| **오늘 할 일 (To Do)** | 오늘 할 일과 담당(사용자·Claude), 사용자가 정해야 하는 것 | — |
| **트러블슈팅** | 어제와 새벽에 막혔던 문제, 원인, 해결 방법, 남은 위험 | 해결한 것은 확인함 |
| **새벽에 한 일 (미검토)** | 사용자가 시키고 잔 뒤 Claude가 한 일 | **아직 확인 안 함** |

| 스크럼 분류 | 업무 보드 칸 |
|---|---|
| 어제 한 일 | 완료 |
| 오늘 할 일 | 할 일, 진행 중, 결정 필요 |
| 새벽에 한 일 | 새벽 작업 · 검토 대기 |

- **새벽에 한 일**에는 결과마다 브랜치·커밋·PR을 적고, 사용자가 봐야 할 점("검토 포인트")을 함께 적습니다.
- 사용자가 검토를 마치면 그 항목은 다음 날 스크럼의 **어제 한 일**로 옮깁니다.
- 트러블슈팅은 "증상 → 원인 → 해결 → 남은 위험" 순서로 짧게 씁니다.

주간 스크럼도 같은 네 분류로 씁니다: **이번 주 한 일**(검토 끝난 일, 날짜별), **다음 주 할 일**, **트러블슈팅**(이번 주 주요 문제, 데일리 링크), **새벽에 한 일**(이번 주에 쌓인 미검토). 맨 위에 이번 주 목표, 맨 아래에 이번 주 숫자(커밋, PR, 테스트 등)를 둡니다.

## 틀

```markdown
# 데일리 스크럼 · YYYY-MM-DD (요일)

## 어제 한 일 (Done)
- (업무 번호) 한 일. 결과 링크

## 오늘 할 일 (To Do)
| 담당 | 업무 | 업무 번호 |
|---|---|---|

결정이 필요한 것:
| 항목 | 필요한 것 | 영향 |
|---|---|---|

## 트러블슈팅
| 문제 | 원인 | 해결 | 남은 위험 |
|---|---|---|---|

## 새벽에 한 일 (미검토)
| 작업 | 업무 번호 | 상태 | 결과 (브랜치·커밋·PR) | 검토 포인트 |
|---|---|---|---|---|
```
